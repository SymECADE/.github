# SymECADE

A Development Ecosystem for Symmetric Multimodal Interaction with Embodied Conversational Agents.

| Repository                                                         | What it is                                                                                  |
|--------------------------------------------------------------------|---------------------------------------------------------------------------------------------|
| [SymECADE](https://github.com/SymECADE/SymECADE)                   | The framework, written in Rust.                                                             |
| [SymECADE-py](https://github.com/SymECADE/SymECADE-py)             | Python bindings for SymECADE.                                                               |
| [SymECADE-cpp](https://github.com/SymECADE/SymECADE-cpp)           | C++ bindings for SymECADE.                                                                  |
| [SymECADE-modules](https://github.com/SymECADE/SymECADE-modules)   | Ready-made modules: speech-to-text, text-to-speech, language models and facial expressions. |
| [SymECADE-examples](https://github.com/SymECADE/SymECADE-examples) | Example applications built with SymECADE.                                                   |
| [unreal-embodiment](https://github.com/SymECADE/unreal-embodiment) | A MetaHuman embodiment, built with Unreal Engine.                                           |
| [web-embodiment](https://github.com/SymECADE/web-embodiment)       | A stick man in the browser as an embodiment.                                                |
| [fer-server](https://github.com/SymECADE/fer-server)               | Live-video facial expression recognition over HTTP.                                         |
